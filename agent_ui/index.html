How to train your agent

Use the same loop from code: reset, read observation, choose action, step, learn from reward.

  1. Reset creates a task episode and returns the first observation.
  2. Valid actions gives safe candidate JSON actions for the current state.
  3. Step applies one action and returns the next observation, reward, done, and info.
  4. Train by repeating this loop from Python, Colab, TRL, GRPO, or your own agent.
